Notes

Every tab is computed by the same Python engine the Streamlit application uses, so results are identical by construction. The browser renders the melt as a live 3D furnace and plays back the engine's frames; the operator controls (charge, power, chemistry, tap aim, additions, speed) drive new engine runs. Advisory only — not a closed-loop plant controller.
